# Blinkit Sales Analytics Dashboard

Tools Used: Power BI, SQL, DAX, Power Query

## Project Overview
Built an interactive dashboard to analyze 10K+ retail records and track KPIs such as sales, ratings, and outlet performance.

## Key Insights
- Sales trend analysis
- Outlet performance
- Product category analysis
- Customer rating insights

📊 Key Features
Developed an interactive Power BI dashboard to track key performance indicators (KPIs) such as:
- Total Sales
- Average Sales
- Item Ratings
- Order Performance
- Performed data cleaning, transformation, and modeling using Power Query and DAX.
- Created dynamic visualizations for:
- Outlet Type Analysis
- Item Category Performance
- Location-wise Sales
- Customer Ratings
